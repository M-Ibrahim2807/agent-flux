# Agent Flux Website

Static marketing website for Agent Flux insurance recruitment.

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Streamlit preview

```bash
streamlit run app.py
```

## Maintenance notes

- Keep page links and image paths validated before deploy.
- Use `images/agent-flux-mark.svg` for the lightweight site logo.
- Replace placeholder social links with verified Agent Flux profiles.
- Connect the contact form to a secure backend before production lead routing.
